## Tailor the emphasis

For analyst applications, lead with dashboard ownership, source-to-target reconciliation and a clear sports finding. For data-science applications, lead with the existing soccer research and this project's temporal validation, baseline and uncertainty. For engineering applications, lead with TCS production pipelines, SQL, automation, data quality and the reproducible warehouse.

Use the resume's exact verified experience. Do not add AWS, Snowflake, tracking-data access, MLOps deployments or professional team impact just because a posting requests them. The portfolio demonstrates a local reproducible pipeline and static dashboard, not a deployed cloud warehouse.

Some roles have explicit authorization limits. For example, the Cardinals platform-engineering posting says it does not sponsor or assume sponsorship, including OPT/CPT. No work-authorization assumption has been made about the applicant. Check the employer's current terms before applying.

## Explain the project in an interview

Start with the scouting question, show a filtered comparison, then trace one metric through additive SQL aggregates to the source records. Explain why the 2025 holdout avoids using future outcomes in training, what Brier score measures, why the improvement is modest, and why observational pass/run gaps are not causal. Show the data checks and a case where a small sample should change the confidence of a conclusion.

The existing soccer counterpressing project supplies deeper soccer-domain evidence; Sideline Lab adds a different sport and an engineering-to-dashboard workflow. Understand and reproduce both before presenting them as independent personal work. No portfolio can guarantee resume selection.
